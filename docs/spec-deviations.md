# Deviations from the design specification

The contracts were first defined in a design specification, `SPEC.md`, which is an internal document and not part of
the repository. This table records where the code deliberately differs from it, so that the decisions are not undone.
Where the two differ, the code is right:

| Specification                                                   | Code                                                                                                                                        | Reason                                                                           |
|-----------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------|
| § 4.2 / § 5.1 `findMany(): array` keyed by IČO / DIČ            | `Ares\Companies` / `Adis\VatSubjects` collections                                                                                           | PHP casts digit-only keys to `int`; lookups must normalise ids                   |
| § 3.3 ids as `CompanyId\|string`, int not addressed             | a single id is `CompanyId\|string` / `VatId\|string` (an int is a `TypeError` under `strict_types`); a wrong list element is `InvalidInput` | IČO and DIČ are identifiers, never numbers                                       |
| § 8 `SectionStatus` pure enum                                   | string-backed: `not_requested`, `ok`, `not_found`, `not_applicable`, `unavailable`, `rejected`                                              | § 3 promises `json_encode`-able DTOs                                             |
| § 8 `CompanyProfile` without shortcuts                          | `isVatPayer(): ?bool`, `hasPublishedAccount(): ?bool`                                                                                       | the answer depends on the section status                                         |
